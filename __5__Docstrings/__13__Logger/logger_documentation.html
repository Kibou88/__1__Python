📋 Documentation Logger.py

Version V1.0.0 | Créé le 2026-01-31 | Modifié le 2026-01-31

🎯 Objectif

Cette classe permet de configurer rapidement un système de journalisation (logging) avec :
  • Gestion automatique des fichiers de logs
  • Rotation quotidienne des fichiers (nouveau fichier chaque minuit)
  • Configuration flexible des niveaux de log
  • Format standardisé et lisible

📊 Variables d'Instance

Variable Type Description
log_name str Nom du fichier de log (extension .log ajoutée automatiquement si absente)
log_dir str Nom du dossier où les fichiers de log seront stockés
log_level str Niveau de log (DEBUG, INFO, WARNING, ERROR, CRITICAL)
logger_name str Nom du logger (extrait du nom du fichier sans extension)
logger logging.Logger Instance du logger Python
current_date str Date actuelle au format YYYY-MM-DD
log_file_name str Nom complet du fichier : YYYY-MM-DD_nom_log.log
time_handler TimedRotatingFileHandler Gestionnaire de rotation temporelle des fichiers de log

📈 Niveaux de Log Disponibles

Format des entrées : date heure | nom_logger | niveau | message

Exemple : 2025-07-11 14:36:12,713 | Application | INFO | Utilisateur connecté

DEBUG - Informations de débogage (développeurs uniquement, PAS EN PRODUCTION)

INFO - Informations générales (connexion utilisateur, traitement de fichier, démarrage de service)

WARNING - Avertissements (utilisation d'API dépréciée, erreurs récupérables, config optionnelle manquante)

ERROR - Erreurs (TypeError, ValueError, exceptions...)

CRITICAL - Erreurs critiques (perte de connexion DB, mémoire saturée, faille de sécurité)

⚙️ Méthodes de la Classe

__init__(log_name="logs.log", log_dir="Logs", log_level="INFO")

Rôle : Initialise l'instance de la classe Logs et configure tous les composants nécessaires.

Paramètres :
  • log_name (str, défaut="logs.log") : Nom du fichier de log
  • log_dir (str, défaut="Logs") : Dossier de stockage des logs
  • log_level (str, défaut="INFO") : Niveau de journalisation

Actions :

  • Ajoute l'extension .log si absente
  • Crée le dossier de logs s'il n'existe pas
  • Initialise le logger, le handler et configure le niveau
init_logger()

Rôle : Initialise l'objet logger de Python.

Actions :

  • Extrait le nom du logger depuis le nom du fichier (sans extension)
  • Crée l'instance logging.getLogger()
init_handler()

Rôle : Configure le gestionnaire de rotation temporelle et le format des logs.

Actions :

  • Crée un TimedRotatingFileHandler avec rotation à minuit
  • Définit le format : date heure | nom | niveau | message
  • Applique le formateur au handler
configure_setLevel()

Rôle : Configure le niveau de journalisation du logger et du handler.

Actions :

  • Utilise un match/case pour définir le niveau selon log_level
  • Si le niveau est invalide ou vide, définit INFO par défaut
  • Applique le niveau au logger ET au handler

Méthodes de Journalisation

log_debug(message)

Rôle : Enregistre un message de débogage (UNIQUEMENT POUR DÉVELOPPEURS).

Paramètre : message (str) - Message à enregistrer

⚠️ Ne pas utiliser en production !

log_info(message)

Rôle : Enregistre un message d'information générale.

Paramètre : message (str) - Message à enregistrer

Exemples d'utilisation : Connexion utilisateur, fichier traité, service démarré

log_warning(message)

Rôle : Enregistre un avertissement.

Paramètre : message (str) - Message à enregistrer

Exemples d'utilisation : API dépréciée, erreur récupérable, configuration optionnelle manquante

log_error(message)

Rôle : Enregistre une erreur.

Paramètre : message (str) - Message à enregistrer

Exemples d'utilisation : TypeError, ValueError, exceptions diverses

log_critical(message)

Rôle : Enregistre une erreur critique.

Paramètre : message (str) - Message à enregistrer

Exemples d'utilisation : Perte de connexion à la base de données, mémoire saturée, faille de sécurité

💡 Exemple d'Utilisation

# Création d'une instance de Logs
try:
    log = Logs(log_name="Test.log", log_dir="Test_Logs", log_level="INFO")
except:
    print("Problème dans la création des logs")
else:
    # Utilisation des différents niveaux de log
    log.log_debug("Message de débogage")      # Ne s'affichera pas (niveau INFO)
    log.log_info("Opération réussie")         # ✅ S'affichera
    log.log_warning("Attention : config manquante")  # ✅ S'affichera
    log.log_error("Erreur de traitement")     # ✅ S'affichera
    log.log_critical("Système compromis !")   # ✅ S'affichera
📁 Résultat :
  • Un dossier Test_Logs sera créé
  • Un fichier 2026-02-01_Test.log sera généré
  • Chaque minuit, un nouveau fichier sera créé automatiquement
  • Les logs seront formatés selon le modèle défini

🔑 Points Clés

  • ✅ Rotation automatique : Nouveau fichier chaque minuit
  • ✅ Nommage horodaté : YYYY-MM-DD_nom.log pour faciliter le tri
  • ✅ Niveau configurable : Adapte la verbosité selon les besoins
  • ✅ Format standardisé : Facilite l'analyse et le débogage
  • ✅ Gestion automatique des dossiers : Création si nécessaire
  • ⚠️ DEBUG non recommandé en production : Trop verbeux
  • ⚠️ Extension .log automatique : Ajoutée si absente
