🎯 Objectif : Classe pour configurer rapidement un logger avec gestion de handlers, rotation de fichiers et niveaux de logs

🔍 Vue d'ensemble

Ce module Python fournit une classe Logs pour simplifier la configuration et la gestion des fichiers de logs. Il utilise le module standard logging de Python avec des fonctionnalités avancées de rotation de fichiers.

✨ Fonctionnalités principales :
  • Création automatique de nouveaux fichiers de log chaque jour à minuit
  • Format de nom standardisé : YYYY-MM-DD_nom_log.log
  • Support de 5 niveaux de log : DEBUG, INFO, WARNING, ERROR, CRITICAL
  • Format de log structuré avec horodatage, nom du logger, niveau et message

📦 Classe : Logs

class Logs()

Description : Classe principale pour la gestion des fichiers de logs avec rotation quotidienne automatique.

⚙️ Méthodes

Méthode d'initialisation

Méthode Description
__init__() Paramètres :
  • log_name (str) : Nom du fichier de log (par défaut : "logs.log")
  • log_dir (str) : Dossier des logs (par défaut : "Logs")
  • log_level (str) : Niveau de log (par défaut : "INFO")
Rôle : Initialise le logger, crée le dossier de logs, configure le handler et le niveau de log

Méthodes de configuration

Méthode Description
init_logger() Paramètres : Aucun
Rôle : Initialise l'objet logger en extrayant le nom depuis le fichier de log
init_handler() Paramètres : Aucun
Rôle : Configure le TimedRotatingFileHandler pour créer un nouveau fichier à minuit et applique le formatage des logs
configure_setLevel() Paramètres : Aucun
Rôle : Configure le niveau de log du logger et du handler selon log_level. Si le niveau est invalide, utilise INFO par défaut

Méthodes de logging

Méthode Niveau Description et usage
log_debug(message) DEBUG Paramètre : message (str)
Rôle : Enregistre des informations de débogage (développeurs uniquement, NON PRODUCTION)
Exemples : Variables internes, états d'exécution
log_info(message) INFO Paramètre : message (str)
Rôle : Enregistre des informations générales
Exemples : Connexion utilisateur, fichier traité, service démarré
log_warning(message) WARNING Paramètre : message (str)
Rôle : Enregistre des avertissements
Exemples : Usage d'API obsolète, erreurs récupérables, configuration optionnelle manquante
log_error(message) ERROR Paramètre : message (str)
Rôle : Enregistre des erreurs
Exemples : TypeError, ValueError, exceptions capturées
log_critical(message) CRITICAL Paramètre : message (str)
Rôle : Enregistre des erreurs critiques
Exemples : Perte de connexion BDD, mémoire saturée, faille de sécurité

📝 Format des logs

Format de sortie :
date heure | nom_logger | niveau_log | message
Exemple :
2025-07-11 14:36:12,713 | Application | INFO | Utilisateur connecté avec succès

Niveaux de log acceptés

Niveau Utilisation Production
DEBUG Informations détaillées pour le débogage ❌ Non recommandé
INFO Événements normaux du système ✅ Oui
WARNING Situations inhabituelles mais gérables ✅ Oui
ERROR Erreurs nécessitant une attention ✅ Oui
CRITICAL Erreurs graves compromettant le système ✅ Oui

💻 Exemple d'utilisation

# Importation de la classe
from logger import Logs

# Création d'une instance de logger
try:
    log = Logs(log_name="Application.log", log_dir="Logs_App", log_level="INFO")
except:
    print("Erreur lors de la création des logs")
else:
    # Utilisation des différents niveaux de log
    log.log_debug("Message de débogage")
    log.log_info("Application démarrée")
    log.log_warning("Avertissement configuration")
    log.log_error("Erreur lors du traitement")
    log.log_critical("Erreur critique système")
⚠️ Points importants :
  • Un nouveau fichier de log est créé automatiquement chaque jour à minuit
  • Le dossier de logs est créé automatiquement s'il n'existe pas
  • Si le niveau de log est invalide, INFO est utilisé par défaut
  • Les logs DEBUG ne doivent pas être utilisés en production
